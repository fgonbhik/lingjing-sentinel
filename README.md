# 京域智城 · 北京智慧城市 3D 大屏

面向人工智能与软件创新竞赛打造的北京智慧城市数字孪生大屏。登录后首先进入城市综合态势中心，通过大屏中的“灵境哨兵”入口进入危化品应急处置演示项目。

## 核心演示

- 3D 北京城市地图、建筑群与昼夜灯光切换
- 左键旋转、滚轮缩放、右键平移与五组缓动飞行视角
- 5,200 栋建筑悬停高亮、单击详情及城区一键聚焦
- 共享 AniNum 数字滚动核心，城市指标与应急决策数据平滑更新
- 左右信息框架采用分层边角、动态能量轨道、标题扫描光带与悬停状态反馈
- 左右栏采用大字号信息层级，指标卡、事件流、智能体、算法和时间线均支持点击联动
- 点击任意数据卡会打开结构化实时数据详情；灵境哨兵仅保留大屏右下角唯一入口
- 演示入口直达北京真实 3D 地图，兼容本地、GitHub Pages 与在线子目录
- 危化品车辆事故全过程自动演示
- AI 事故图片识别与置信度分析
- 有毒气体扩散范围、风向和风险等级推演
- 封路后的真实道路路径重规划
- 消防车、救护车、警车出警与社会车流模拟
- 资源调度、预案处置和应急报告交互
- 登录、注册与大屏指挥界面

## 本地运行

环境要求：Node.js 22.13 或更高版本。

Windows 用户可直接双击项目根目录中的 `启动演示.bat`。启动器会直接运行已经构建好的离线演示文件并打开 `http://127.0.0.1:3000`，无需安装依赖；如果电脑未安装 Node.js，则自动打开在线演示版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址。生产构建与测试：

```bash
npm run build
npm test
```

## 演示建议

登录系统后先展示北京智慧城市 3D 大屏；点击右下角唯一的“灵境哨兵”演示入口，再按时间线展示事故识别、风险扩散、封路重规划和多部门协同处置。两个界面均支持地图旋转、缩放、昼夜切换及建筑交互。

## 可答辩 AI 证据

- 浏览器本地运行 YOLO-26n Fire & Smoke ONNX 模型，断网仍可完成烟雾、火焰目标检测。
- 评委可上传 JPG、PNG 或 WebP 图片，查看类别、目标框、置信度、推理耗时和结果解释。
- 内置 7 例小型回归集，界面展示 Accuracy、Precision、Recall、F1、混淆矩阵和误判样本。
- 清楚区分四类能力：ONNX 视觉识别、高斯烟羽物理模型、OSM 路网 A* 算法、规则化多智能体协同。
- 多智能体审计中心展示任务输入、消息流、决策依据和可导出的 JSON 审计日志。
- 模型无法加载时会明确切换为“端侧可解释视觉研判原型”，不会冒充深度学习结果。

复现实测：

```bash
npm run ai:evaluate
```

证据来源、样本许可和指标口径见 `AI_EVIDENCE.md`；固定演示路径与验收要求见 `DEMO_ACCEPTANCE.md`。

> 本项目中的事件、识别结果和调度数据用于竞赛演示，不作为真实应急处置依据。
