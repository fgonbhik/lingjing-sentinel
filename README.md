# 京域智城 · 北京智慧城市 3D 大屏

面向人工智能与软件创新竞赛打造的北京智慧城市数字孪生大屏。登录后首先进入城市综合态势中心，通过大屏中的“灵境哨兵”入口进入危化品应急处置演示项目。

## 核心演示

- 3D 北京城市地图、建筑群与昼夜灯光切换
- 左键旋转、滚轮缩放、右键平移与五组缓动飞行视角
- 5,200 栋建筑悬停高亮、单击详情及城区一键聚焦
- 共享 AniNum 数字滚动核心，城市指标与应急决策数据平滑更新
- 左右信息框架采用分层边角、动态能量轨道、标题扫描光带与悬停状态反馈
- 演示入口直达北京真实 3D 地图，兼容本地、GitHub Pages 与在线子目录
- 危化品车辆事故全过程自动演示
- AI 事故图片识别与置信度分析
- 有毒气体扩散范围、风向和风险等级推演
- 封路后的真实道路路径重规划
- 消防车、救护车、警车出警与社会车流模拟
- 资源调度、预案处置和应急报告交互
- 登录、注册与大屏指挥界面

## 本地运行

环境要求：Node.js 22.13 或更高版本。

Windows 用户可直接双击项目根目录中的 `启动演示.bat`。启动器会直接运行已经构建好的离线演示文件并打开 `http://127.0.0.1:3000`，无需安装依赖；如果电脑未安装 Node.js，则自动打开在线演示版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址。生产构建与测试：

```bash
npm run build
npm test
```

## 技术栈

- React 19 / TypeScript
- Three.js 城市三维可视化
- vinext / Vite
- CSS 动画与响应式大屏布局

## 演示建议

登录系统后先展示北京智慧城市 3D 大屏；点击顶部或右侧的“灵境哨兵”演示入口，再按时间线展示事故识别、风险扩散、封路重规划和多部门协同处置。两个界面均支持地图旋转、缩放、昼夜切换及建筑交互。

> 本项目中的事件、识别结果和调度数据用于竞赛演示，不作为真实应急处置依据。
