# 灵境哨兵 · 城市危化品应急智能决策平台

面向人工智能与软件创新竞赛打造的沉浸式应急指挥演示系统。项目以北京城市路网为场景，完整演示危化品运输车辆故障、事故图片识别、风险扩散计算、道路封控、消防/医疗/警力协同调度以及处置报告生成。

## 核心演示

- 3D 北京城市地图、建筑群与昼夜灯光切换
- 危化品车辆事故全过程自动演示
- AI 事故图片识别与置信度分析
- 有毒气体扩散范围、风向和风险等级推演
- 封路后的真实道路路径重规划
- 消防车、救护车、警车出警与社会车流模拟
- 资源调度、预案处置和应急报告交互
- 登录、注册与大屏指挥界面

## 本地运行

环境要求：Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址。生产构建与测试：

```bash
npm run build
npm test
```

## 技术栈

- React 19 / TypeScript
- Three.js 城市三维可视化
- vinext / Vite
- CSS 动画与响应式大屏布局

## 演示建议

进入系统后点击“启动智能推演”，按时间线展示事故识别、风险扩散、封路重规划和多部门协同处置；地图支持旋转、缩放、昼夜切换及资源交互。

> 本项目中的事件、识别结果和调度数据用于竞赛演示，不作为真实应急处置依据。
